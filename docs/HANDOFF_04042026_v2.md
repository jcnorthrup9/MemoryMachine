## What the App Does Right Now

Memory Machine is a single-page architectural remix tool for Pershing Square, DTLA.

1. **2D Remix tab** — Stack diagram layers from 4 reference parks onto the Pershing Square boundary, clipped to the actual park polygon, export as SVG/JPEG
2. **3D Preview tab** — Auto-loads `PershingSQCurrent.obj` (the actual Rhino model) as a baseline when the tab is clicked. "Deploy to 3D" draws the remix stack on top as `THREE.Line` objects. Draft/Dream toggle switches between SVG line extrusion and ComfyUI mesh generation (stub).
3. **Generate Intervention** — AI narrative + precedent search via Gemini + ChromaDB
4. **Bake to Rhino** — Sends geometry back to the live Rhino session

**Stack:** FastAPI (`app.py`) + vanilla JS SPA (`templates/index.html`) + CSS (`static/style.css`). No build step. Run with `uvicorn app:app --reload`.

## Changes Made This Session (04-04 afternoon)

### OBJ ↔ SVG Coordinate Space — FIXED

This was Priority 1 from the previous handoff. The OBJ model vertices were ~±1300 Rhino units while the SVG-derived stack lines used `SVG_SCALE = 0.04` → ~±25 world units. They didn't overlap.

**Fix applied in `buildPershingContext()` (both MTL-success and MTL-fallback branches):**

```javascript
// Scale OBJ to match SVG world space (Pershing viewBox 1224pt × SVG_SCALE 0.04 ≈ 49 units)
const targetSpan = 1224 * SVG_SCALE;
const objSpan    = Math.max(size.x, size.z);
const objScale   = targetSpan / objSpan;
obj.scale.setScalar(objScale);

// Center XZ at world origin; sit bottom on ground (scale-aware)
obj.position.x = -center.x * objScale;
obj.position.z = -center.z * objScale;
obj.position.y = -box.min.y * objScale;

threeScene.add(obj);
_threeOrbitSph.r = targetSpan * 2.0;  // ≈ 98 units — good overview distance
```

Camera and fog also updated to match the new scale:
- `camera.far`: 20000 → **5000**
- Fog density: 0.0002 → **0.0005**
- Initial orbit radius: 2200 → **80** (pre-load), **~98** (post-load)

The OBJ and any deployed stack lines now share the same coordinate space.

## Known Issues / What Needs Work

### Priority 1 — OBJ Orientation (may or may not be needed)
Rhino can export Z-up. If the model appears lying on its side in the 3D tab, add this line inside `buildPershingContext()` right before `obj.scale.setScalar(objScale)`:
```javascript
obj.rotation.x = -Math.PI / 2;
```
If the model already looks correct (top-down = roof of buildings visible), skip this.

### Priority 2 — ComfyUI Bridge (Stub Only)
`generate_comfyui_mesh()` in `app.py` currently returns `{ glb_url: null }`.
When ComfyUI is running at `localhost:8188`, replace with:
```python
workflow = build_comfyui_workflow(prompt, footprint)
res = requests.post("http://localhost:8188/prompt", json={"prompt": workflow})
glb_path = poll_comfyui_output(res.json()["prompt_id"])
return {"glb_url": f"/static/generated/{os.path.basename(glb_path)}", "footprint": footprint}
```
Frontend expects `glb_url`, `footprint`, `site`, `layerId`, `label` per mesh item.

### Priority 3 — 3D Tab Init Race Condition
`buildPershingContext()` fires 100ms after tab click. On slow machines the canvas may still be 0×0. Consider using a `ResizeObserver` on `#three-canvas` instead of a fixed timeout.

### Priority 4 — General Code Split
All JS is inline in one ~1820-line HTML file. Could be split into `static/main.js` without any other changes needed to the app.
