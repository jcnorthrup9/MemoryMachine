# TODO.md: Memory Machine – Complete Pipeline Blueprint

## 1. Universal Site Ingestion Framework (Rhino/Grasshopper Input)
*Do NOT remodel the site. Build an ingestion pipeline that reads your existing geometry and maps it as parametric variables so the app can be pointed at any site.*

- [ ] **Geometry Reference Pipeline:**
  - Set up Grasshopper pipeline inputs to reference your existing Pershing Square Rhino geometry (Slabs, Columns, Bounds).
  - Parameterize these inputs into generalized data streams so they can be replaced by any other site's geometry (e.g., inputting a new boundary curve or a different structural column interval).
- [ ] **Structural Grid Analyzer (Python Component):**
  - Write a Python script component that automatically detects structural intervals from the referenced column geometry (for Pershing, it extracts the true 27-foot column grid spacing).
  - This keeps the logic universal: if a site has a 20-foot grid, or an irregular structure, the script calculates excavation safety boundaries based on detected column vectors rather than hardcoded dimensions.

## 2. Universal Data Ingestion & Metric Mapping
*Translates scraped data streams and live reviews into normalized spatial influences across any given site footprint.*

- [ ] **Malleable Sentiment & Amenity Parser:**
  - Build/clean the classification script to categorize scraped site data into normalized matrix fields: Atmospheric/Sentiment, Amenity Deficit (e.g., "lacks green space," "no shade"), and Spatial Experience.
- [ ] **The Spatial Grid Vector Map:**
  - Map these data registers as scalar values (0.0–1.0) across the referenced site footprint. High amenity deficits or high solar radiation values act as excavation triggers, regardless of whether the site shape is an elongated rectangle or an irregular polygon.

## 3. Parametric Terracing & Excavation Engine ("Metabolizer v2")
*Replaces the static diagram tool with a live, rule-based structural erosion processor.*

- [ ] **Structural Constraint Solver (Allowable Structural Degradation):**
  - Write a Python component that calculates "allowable excavation zones" based on proximity to referenced column vectors.
  - Rule: Establish a hard "Column Keep-Out Zone" radius (e.g., 4–5 feet) around the 27-foot column coordinates to maintain structural integrity and create a deep, brutalist cavern aesthetic.
- [ ] **Adaptive Canyon Step Generator:**
  - Generate the downward canyon terracing by using the data vectors to drive section cuts through the parking slabs down toward the Metro tunnel interface.
  - Rule: Set a terracing ratio where every vertical drop of 1 story (~10–12 feet) requires a horizontal step-back of at least half a bay (13.5 feet).
- [ ] **The Botanical Attractor Module (The Infill Matrix):**
  - Create a procedural growth component inspired by the structural canopy logic of the UCLA Mathias Botanical Garden.
  - Depth Triggers: Level 0 (Surface = Shade canopies/trees); Level -1 (Upper Canyon = Terraced concrete planters/ferns); Level -2/-3 (Deep Canyon/Metro = Structural sub-vaults, wetland pockets, and micro-climate flora).

## 4. Headless High-Fidelity Pipeline (Blender bpy)

- [ ] **Headless Data Ingest (bpy Script):**

  - Create a Geometry Nodes template that adds high-fidelity material weathering, concrete erosion, and organic vegetative growth over time to the ingested steps.
- [ ] **Optimized Mesh Exporter:**

## 5. Spatio-Temporal Interaction & Unity Sandbox

## 6. Automated Representation & Vector Export Engine (Rhino/Python)
*Builds a tool to programmatically generate clean, layered 2D vector drawings for post-processing and AI training input.*

- [ ] **Dynamic Section/Plan Slicer:**
  - Create a Grasshopper pipeline that generates vertical section cuts along the 27-foot column paths and horizontal plan cuts through the 3 garage levels.

- [ ] **Automated Axonometric Projector:**
