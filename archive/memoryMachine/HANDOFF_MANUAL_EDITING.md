**Date:** 2026-04-07
**Focus:** Parametric UI Sliders & Zonal Constraints HUD

## The Goal
We want to allow the user to manually tweak the 2D layout generated by the engine. The user should be able to select a layer from the stack and adjust its X, Y, Scale, and Rotation using UI sliders, seeing the results update live on the 2D canvas. We also want a HUD to show if their layout complies with our urban design guidelines.
