### 3. Bug Fix — `static/main.js`: Silent SVG Cache Miss

**Problem:** AI responses from `/api/generate` include `spatial_seed` items from precedent sites (ParcdelaVillette, ZaryadyePark, etc.). `engine2D.js` checks `MemoryState.svgCache[item.site]` before rendering each layer — if the SVG isn't cached, the layer is silently skipped. Result: cross-pollinated sites never appeared on the 2D canvas.

**Fix:** Pre-fetch loop inserted in `generate()` between receiving `data` and mapping `MemoryState.stack`:

```js
const missingSites = [...new Set(
  data.spatial_seed
    .map(s => s.site || 'PershingSquare')
    .filter(site => !MemoryState.svgCache[site])
)];
if (missingSites.length > 0) {
  setStatus(`Fetching ${missingSites.length} precedent site(s)…`, 'running');
  await Promise.all(missingSites.map(site => fetchSVG(site).catch(err => {
    appendToTerminal(`⚠ Could not load SVG for ${site}: ${err.message}`, 'line-muted');
  })));
}
```

`Promise.all` fetches in parallel. Individual failures surface as muted terminal lines and do not abort the render of other sites.

## Current Architecture

```
index.html          ← served by app.py (FastAPI FileResponse)
static/
  style.css         ← full app styles, Retro-Futuristic aesthetic
  main.js           ← app controller (generate, 3D scene, events)
  js/
    constants.js    ← SITES, TARGET_LAYERS, COORDINATE_SYSTEM → window.*
    state.js        ← MemoryState, setStatus → window.*
    engine2D.js     ← Engine2D.render(), window.renderRemixSVG
templates/
  index.html        ← legacy template (Jinja), now also modularized
app.py              ← FastAPI router only (no inline logic)
logic/
  ai_synthesizer.py
  urban_engine.py
  geometry_engine.py
```

**`/api/generate` response shape (what main.js expects):**
```json
{
  "status": "success",
  "narrative": "...",
  "diagram": "graph TD ...",
  "spatial_seed": [
    { "site": "ParcdelaVillette", "layerId": "GREEN_SPACE",
      "transform": {"x": 0, "y": 0, "scale": 1.0, "rot": 0} }
  ],
  "geometries": [
    { "type": "box", "args": [10, 5, 10], "position": [0, 2.5, 0], "color": "#6b6460" }
  ]
}
```

**`/api/available-sites` response shape (used to populate dropdown):**
```json
{ "sites": [{ "id": "PershingSquare", "name": "Pershing Square", "bounds": {...} }] }
```
> Note: This endpoint is called in `main.js` `init()` but **may not yet exist in `app.py`**. If the call 404s, the dropdown falls back to the static HTML options — not a hard failure.
