# 🧠 Memory Machine // Development Sprint Log
**Date:** April 1, 2026
**Focus:** Interactive SVG Viewer, Rule Standardization, and IronPython Debugging

## 1. Strategic Pivot: Interactive SVG Viewer
- **The Pivot:** Shifted focus away from the AI autonomously drafting geometry in Rhino via the MCP. Instead, the machine acts as an analyst of human-authored architectural diagrams.
- **The App:** Built a new split-screen interactive dashboard (`/diagrams` endpoint). It renders raw SVGs exported directly from Rhino on a clean white pane on the left, and the AI's parsed "Spatial DNA" JSON on a dark data panel on the right.
- **Interactivity:** Added hover interactivity. Hovering over a zone/path card dims all non-matching SVG layers and adds a glowing drop-shadow filter to the matching one. Hovering an SVG layer highlights the corresponding data cards.
- **Asset Management:** Rerouted the backend to serve vector graphics explicitly from `data/ParkSVG/`. Made the JSON blueprint optional so sites with an SVG but no parsed data (like Pershing Square currently) still render gracefully.

## 2. Diagramming Rule Standardization
- Authored `DIAGRAM_RULES.md` to serve as the absolute source of truth for diagramming.
- **Layer Taxonomy:** Locked in specific layer names (e.g., `Hardscape Plaza`, `Main Attractors`, `Pedestrian Pathways`) that map directly to the JSON blueprint schema.
- **Coordinate Anchoring:** Established a strict constraint where the bottom-left corner of the satellite `PictureFrame` must sit at the world origin `(0,0,0)`, and all drafting must occur flat on the `Z = 0.0` plane.

## 3. Rhino Script Stability
- Debugged a fatal crash in `logic/one_click_diagram.py` caused by Rhino 8's internal IronPython 2.7 environment lacking support for Python 3's `subprocess.run()`.
- Refactored the vision tracer execution to use a backwards-compatible `subprocess.Popen` and `.communicate()` pipeline, with robust UTF-8/ASCII error handling for stdout streams.

## 4. UI/UX Bug Fixes
- Resolved JS syntax and HTML linter truncation errors that were breaking the SVG container layout and site dropdown.
- Updated API endpoints to use case-insensitive matching between `.svg` stems and `_rhino_parsed.json` stems.
