00 // STATEMENT

MEMORY
MACHINE

Memory is not a static archive, but an unstable process of encoding, retrieval, and decay; it shifts, collapses and rewrites itself constantly. Because of this, architecture must move beyond a static container and become a dynamic interface embedded in public life. Memory Machine addresses under-utilized public space by converting community reviews into spatial data and reimagining the site as a high-performing park that is natively responsive to its users.
JOHN NORTHRUP

04 // SPECIFIC OBJECT Pershing Square

Los Angeles, CA — Downtown · Est. 1866

Los Angeles' oldest public park. A site of dense public memory — historically a speaker's corner, political gathering ground, and urban anchor.

THE PROBLEM
The 1994 redesign by Ricardo Legorreta produced a concrete bunker that severs the square from surrounding streets. No shade. No programming. A heat island in one of the hottest urban cores in North America.
THE PARADOX
One of the busiest Metro stations in LA sits directly below — the Red and Purple lines. Thousands of commuters pass through daily, but surface dwell time approaches zero. The infrastructure exists; the activation does not.
WHY THIS SITE
High public memory density. Documented failure. Existing infrastructure to leverage. A site where the three-phase output can be demonstrated concretely — and verified against real conditions.

07 // CASE STUDIES
→ Phase 01 // Site Activation

High Line

Diller Scofidio + Renfro · New York · 2009

Elevated rail infrastructure converted to linear public park. Infrastructure that passed over the city without engaging it becomes the primary public armature. Transit as activator, not barrier — exactly the inversion Pershing Square requires.

→ Phase 02 // Programming

SESC Pompeia

Lina Bo Bardi · São Paulo · 1977–86

Adaptive reuse of a drum factory as a layered cultural and social center. Industrial memory preserved; democratic public program injected over and through it. A model for activating a dormant site without erasure.

→ Phase 03 // Connection

Zeitz MOCA

Heatherwick Studio · Cape Town · 2017

Grain silos carved out to create gallery volumes. The existing industrial structure is not erased — it is excavated, punctured to reveal new program. Scars of the original remain as the aesthetic logic. The activation is in the cut.
